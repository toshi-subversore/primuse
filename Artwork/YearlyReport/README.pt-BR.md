# Ilustrações da retrospectiva anual

Este conjunto de ilustrações não é distribuído atualmente dentro do pacote do app; em dispositivos 3x ele adicionaria aproximadamente 27,5 MB.

Quando as imagens não estão disponíveis, cada cartão da retrospectiva anual usa um SF Symbol como fallback. Consulte `YearlyArtView`.

Para restaurar as ilustrações, mova este diretório inteiro de volta para `Primuse/Resources/Assets.xcassets/YearlyReport`. Os nomes dos recursos não precisam ser alterados.
