## Escopo

`AGENTS.md` não é traduzido aqui porque contém instruções internas de execução para agentes e automações, e não documentação destinada ao usuário ou contribuidor. Duplicar esse arquivo em outro idioma criaria duas fontes de instrução operacional que poderiam divergir.
